# Changelog

## 1.2.0

First public release.

- Original DOC → PDF app icon, with Retina and small-size variants.
- Native drag-and-drop and Finder Open With integration.
- English default language and full Hungarian localization.
- Self-contained, offline conversion with the official LibreOffice 26.8.2.2 engine.
- Compressed Apple Silicon DMG with an Applications shortcut and bilingual instructions.
- Reproducible build scripts, engine checksums, license notices and integration checks.

This build is ad-hoc signed and is not notarized by Apple. Intel Macs are not supported.
